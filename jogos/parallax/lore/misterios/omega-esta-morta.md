# A Ômega está morta?

O Setor Nulo foi soterrado, mas continua morno. A IA parece ativa.

## O que cada olhar sugere

- **Goliath:** a fornalha do setor funciona sem ninguém para aquecer.
- **Phantom:** os autômatos patrulham rotas que ninguém programou.
- **Cipher:** o campo `VAZAMENTO DETECTADO` continua a contar.
