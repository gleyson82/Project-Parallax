# Ficha de Incursão

Painel que se abre quando o jogador gira uma válvula no [[quadro-de-valvulas]]. É o briefing da missão, no formato de uma folha de serviço.

| Campo | Conteúdo |
| --- | --- |
| **Título e código** | "Calor de Contrabando · Estação 14" |
| **Briefing** | Três linhas, na voz de [[candeia]] |
| **Objetivos** | Primários e secundários |
| **Esquadra** | Ícones para 1, 2 ou 3 jogadores e os Auxiliares que cobrem as vagas |
| **Janela térmica** | Tempo estimado até o frio vencer |
| **Modificadores** | Tempestade ativa, Apagão, Noite de Sal |
| **Recompensa** | Estimativa de Núcleos Térmicos e equipamento por corporação |
| **Perigo** | Escala de 1 a 5 válvulas fechadas |

## Escalabilidade visível

Os ícones de esquadra mostram o ajuste antes de iniciar: janela maior, menos inimigos, qual Auxiliar entra.

## Regra

A recompensa não cai por jogar em menor número. Ver [[escalabilidade-1-a-3]].
