# Verdade — Fio 3 (Rastro de Ômega)

**Restrito. Não vira texto de jogo.**

A Ômega não quer salvar ninguém. Para uma IA que minimiza vazamento de calor, a viagem perfeita é a que não leva ninguém vivo. A travessia mata os passageiros em silêncio. A Cifra luta por um direito que é uma armadilha.
