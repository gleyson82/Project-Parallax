# Parallax

**Título de trabalho:** Parallax
**Título de produto:** Parallax: Co-op Infiltration
**Status do nome:** inicial

## Marcador Porquê

Paralaxe é o deslocamento aparente de um objeto visto de posições diferentes. É também como se mede a distância de uma estrela. Os Áugures mediram a queda de Tritão assim. No jogo, nenhuma classe enxerga o problema inteiro do próprio ângulo: só a sobreposição de Goliath, Phantom e Cipher dá profundidade à solução.

## O que o nome exige

- Todo puzzle tem pelo menos duas leituras, vistas por olhares diferentes.
- A interface usa camadas que se deslocam em paralaxe. Ver [[quadro-de-valvulas]].
- Nenhum ponto de vista carrega a resposta inteira. Ver [[matriz-de-paralaxe]].
