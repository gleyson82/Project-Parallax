**Studio:** HTL Games

## O Labirinto
Bem-vindo ao Project Daedalus. Este é o cérebro narrativo da HTL Games, onde construímos a lógica, a história e os mistérios que habitam os nossos mundos. Aqui, não escrevemos roteiros passivos; nós arquitetamos labirintos para a mente dos jogadores.

## Os 3 Pilares Narrativos da HTL Games

Para qualquer IA ou colaborador que opere neste repositório, estas são as leis inquebráveis de design:

1. **A Mecânica Dita, a Lore Justifica (Gameplay First):**
   A narrativa existe para servir e dar contexto elegante às restrições técnicas e mecânicas do jogo. O limite do código é a fronteira da história, nunca o contrário.
2. **Informação Assimétrica como Ferramenta:**
   Os personagens e os jogadores nunca têm a resposta completa sozinhos. A lore é fragmentada intencionalmente para forçar comunicação, dedução e exploração.
3. **O Jogador é o Arqueólogo:**
   Não damos exposições longas. Contamos a história através de design de ambiente, regras matemáticas, mistérios ambientais e *puzzles* lógicos.

## O Arquivo

A lore de cada jogo fica em [`jogos/`](jogos/README.md). A planta para um jogo novo está em [`modelo/`](modelo/README.md). Convenções, guia de voz e decisões de lore estão em [`studio/`](studio/convencoes.md).

O primeiro jogo do arquivo é [Parallax](jogos/parallax/indice.md) (*Parallax: Co-op Infiltration*), um jogo para 1 a 3 jogadores. O vault foi organizado por assunto (lore, facções, classes, itens, biomas, quests, raids, interface), pensado para abrir no Obsidian.
