# Menu principal — A Sala de Máquinas

Inspirado no Diretor de Destiny, adaptado ao industrial e cibernético de Tritão. O jogo abre em um espaço, e não em uma lista.

## Abertura

Tela preta. Um zumbido grave, a **nota do piso**, sobe até 50 Hz. O logotipo PARALLAX aparece em duas camadas desalinhadas, como duas chapas de metal vistas de ângulos diferentes. Quando o jogador pressiona qualquer botão, as camadas deslizam e se encaixam em uma só palavra.

Geada nas bordas da tela. Se o menu fica parado, o frio avança do canto para o centro. Qualquer entrada empurra a geada de volta.

## Itens, como interruptores físicos

| Item | Função |
| --- | --- |
| **Quadro** | Abre o [[quadro-de-valvulas]], o mapa de missões |
| **Esquadra** | Escolha de classe, Auxiliares e equipamento |
| **Forja** | Gasta [[nucleo-termico]] em modificadores e talentos |
| **Sinal** | Arquivo de fragmentos já lidos, com fonte e hora |
| **Linha** | Convite e sessão (1 a 3 jogadores) |
| **Ajustes** | Vídeo, áudio, acessibilidade, controles |

Cada item é um interruptor que o jogador gira, com um estalo mecânico.

## Navegação

- **Direcional:** gira um volante central entre os itens.
- **Confirmar:** segurar por 0,4 s. O gesto evita erro e dá peso ao ato.
- **Voltar:** fecha a válvula (animação curta).
- **Botão de camada:** alterna entre as camadas de leitura. Ver [[quadro-de-valvulas]].

## Estética

Estêncil industrial, ferrugem, aço escuro com condensação, amarelo-enxofre para destaque, ciano-gelo para frio, violeta para Krios-Prime.
